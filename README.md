# netget-net/tap

Homebrew tap for [NetGet](https://github.com/netget-net/netget).

```bash
brew install netget-net/tap/netget
```

The formula installs the prebuilt release binary for macOS (Apple Silicon and Intel) and glibc
Linux (x86_64 and arm64). Its source of truth is `packaging/homebrew/netget.rb` in the NetGet
repository; update both together when a release is cut.
